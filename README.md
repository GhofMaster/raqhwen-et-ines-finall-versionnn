# دعوة زفاف Radhwen & Ines — دليل التعديل

## هيكل المجلد
```
invitation/
├── index.html        ← الصفحة نفسها (النصوص، الأقسام، الصور)
├── css/style.css      ← كل الألوان والأشكال والخلفية المتحركة
├── js/music.js        ← إعدادات الموسيقى (سهل التعديل)
├── js/main.js         ← تفاعل الصفحة (فتح الظرف، العد التنازلي، المشاركة)
└── music.mp3          ← (اختياري) ضعوا هنا أغنيتكم الخاصة بهذا الاسم بالضبط
```

افتحوا `index.html` مباشرة في المتصفح لمعاينة الدعوة، أو ارفعوا المجلد كاملاً على أي استضافة (Netlify، GitHub Pages، إلخ).

---

## 1) تغيير نوع الموسيقى
افتحوا الملف `js/music.js`. في الأعلى ستجدون:

```js
const MUSIC_CONFIG = {
  instrument: "oud",   // غيّروها إلى: "qanun" أو "ney" أو "piano"
  tempoMs: 900,         // رقم أصغر = إيقاع أسرع
  volume: 0.5,          // من 0 إلى 1
  ...
};
```
- `instrument`: `"oud"` (عود)، `"qanun"` (قانون)، `"ney"` (ناي)، `"piano"` (بيانو ناعم).
- `scale`: مجموعة النغمات؛ جربوا مجموعة أخرى للحصول على طابع مقام مختلف (أمثلة داخل الملف).
- `tempoMs` و `restChance`: للتحكم في سرعة وكثافة العزف.

**لاستعمال أغنية حقيقية بدلاً من الموسيقى المولّدة**: ضعوا ملف MP3 خاص بكم (يجب أن تملكوا حقوقه أو ترخيصاً لاستعماله) باسم `music.mp3` داخل هذا المجلد بجانب `index.html`. ستُشغَّل تلقائياً بدل الموسيقى المولّدة، دون أي تعديل إضافي على الكود.

---

## 2) تغيير الخلفية خارج البطاقة (كانت سوداء)
افتحوا `css/style.css` وابحثوا عن هذا الجزء في الأعلى:

```css
body{
  ...
  background-color:#3a0f1c;
  background-image:
    radial-gradient(...),
    url("data:image/svg+xml,...")   /* الزخرفة الهندسية الإسلامية */,
    linear-gradient(160deg,#6d1429,#3a0f1c 55%,#2a0a15);
  ...
  animation:driftPattern 60s linear infinite;   /* حركة بطيئة للزخرفة */
}
```
- لتغيير الألوان: بدّلوا القيم داخل `linear-gradient(...)` (مثلاً إلى أخضر أو كحلي).
- لتغيير سرعة الحركة: غيّروا `60s` إلى رقم أصغر (أسرع) أو أكبر (أبطأ).
- لتغيير شكل الزخرفة نفسها: يمكن استبدال رابط الـ SVG بزخرفة إسلامية أخرى (نجمة ثمانية، مثلثات، إلخ) من نفس الطراز.

---

## 3) تعديل النصوص والتواريخ
كل النصوص المكتوبة (أسماء العائلة، البرنامج، العنوان، التاريخ) موجودة مباشرة داخل `index.html`، ويمكن تعديلها كأي نص عادي دون الحاجة لأي معرفة برمجية.

موعد العد التنازلي موجود في `js/main.js`:
```js
const target = new Date('2026-10-26T18:30:00+01:00').getTime();
```

---

## 4) الألوان العامة للدعوة
في أعلى `css/style.css` مجموعة الألوان الأساسية:
```css
:root{
  --wine:#5e1026;   /* اللون الأساسي الغامق */
  --gold:#c19a49;   /* لون الذهبي */
  ...
}
```
تغيير هذه القيم يغيّر لون الدعوة بالكامل تلقائياً.
